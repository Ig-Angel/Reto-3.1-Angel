# Proyecto CRUD Ángel Reto 3.1

## Requisitos para que funcione
Tener instalado XAMPP.
Clonar este repositorio en htdocs desde git.

## Configuración de la BBDD
Accede a phpmyadmin desde xampp si te es más cómodo.
Crea una base de datos llamada restapi.
Importa el archivo restapi.sql que se encuentra en la carpeta bbdd de la raíz del proyecto.

## Uso
Abre tu navegador en http://localhost/nombrecarpeta/index.html
